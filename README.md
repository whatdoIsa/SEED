# SEED — 주식 습관 트레이닝

잃어도 되는 돈으로 천 번 연습하는 주식 입문 앱입니다. 실시간 시세를 받아오는 모의투자가 아니라, **에이전트들이 호가를 내고 주문장이 체결시키는 자체 시장 시뮬레이션 엔진** 위에서 거래 습관을 훈련합니다.

- 플랫폼: iOS 18.0+ (iPhone) / SwiftUI
- 상태: App Store 심사 제출 (2026.07, v1.0 — 앱 + IAP 3종 + 구독 2종)
- 외부 의존성: 없음 (Apple 프레임워크 + 로컬 Swift Package만 사용)

## 왜 실시간 시세를 쓰지 않았나

실제 시세 기반 모의투자는 운이 실력처럼 보이는 문제가 있습니다. SEED는 시장 자체를 시뮬레이션하기 때문에 폭락, 급등, 상한가, 지루한 횡보장을 의도적으로 재현할 수 있고, 사용자는 "가격이 왜 움직였는지"를 직접 겪으면서 배웁니다. 가격은 외부 데이터가 아니라 **주문 매칭의 결과물**입니다.

## 저장소 구성

```
JurinKit/     시장 시뮬레이션 엔진 — 로컬 Swift Package (~2,500 LOC, 테스트 105개)
SEED/         Xcode 프로젝트 — 앱 타깃 + WidgetKit 익스텐션 (~17,500 LOC)
server/       AI 튜터용 Cloudflare Worker (API 키 비노출 프록시)
```

## JurinKit — 주문장 기반 시장 엔진

앱과 분리된 순수 Swift Package로, 엔진 로직 전체가 단위 테스트 대상입니다.

- **가격-시간 우선순위 주문장 매칭**: 마켓메이커·노이즈·추세추종·가치투자 4종 에이전트가 지정가 주문을 내고, 체결이 가격을 만듭니다. 시장가 주문은 다단계 체결·평균 체결가·슬리피지를 담은 `FillResult`를 반환하고, 온보딩의 슬리피지 튜토리얼이 이 값을 그대로 사용합니다.
- **결정론적 재현**: SplitMix64 기반 시드 RNG — 같은 시드는 같은 시장을 만듭니다. 시장 전체 충격(기후 모델)도 (시드, 틱)의 순수 함수로 설계해 어떤 순서로 조회해도 리플레이가 일치합니다.
- **한국 시장 미시구조**: 수수료·세금·상하한가 가격 밴드·거래일·동시호가(개장/마감)를 구현했습니다.
- **자전거래 방지(STP)**: 사용자 시장가 주문이 본인의 미체결 지정가를 건너뛰도록 `excluding` 파라미터로 처리 — 이 기능이 유발한 주문장 스캔 성능 회귀(시작 25초+)를 찾아 수정한 기록이 커밋 히스토리에 있습니다.
- **테스트**: XCTest 105개 (체결·지정가·동시호가·시나리오·터틀/퀀트 전략·ETF·멀티심볼·성능).

## 앱 아키텍처 — MV 패턴

뷰모델 없이 `@Observable @MainActor` 상태 객체가 도메인별 단일 진입점을 맡습니다.

- `MarketSession` — 엔진 구동 (엔진에는 타이머가 없고, 세션이 1x/5x/30x 배속으로 스텝을 밈)
- `SeedStore` — SwiftData 단일 게이트웨이 (뷰는 SwiftData를 직접 만지지 않음)
- `PurchaseStore` — StoreKit 2 (`Transaction.updates` 리스너, 로컬 `.storekit` 테스트 구성)
- 영속화: SwiftData 5개 모델 + CloudKit private DB 동기화, iCloud 불가 시 로컬 폴백. 30만 스텝 초과 시 원장을 재기준선으로 압축해 동기화 부담을 억제합니다.
- 차트는 직접 그립니다: `ChartCanvas`가 Canvas 위에 캔들·거래량·이동평균·현재가/평단 배지·핀치 줌·전체화면 회전을 렌더링 (외부 차트 라이브러리 미사용).
- WidgetKit 홈/잠금화면 스트릭 위젯 (App Group 공유 + `seed://` 딥링크).

## AI 튜터 — 3중 가드레일과 비용 방어

금융 앱 특성상 "종목 추천·가격 예측·수익 보장 금지"를 카피가 아니라 코드로 강제했습니다.

1. **규칙 필터** (0토큰): 추천/예측성 질문은 클라이언트에서 즉시 거절
2. **용어집 매칭** (0토큰): 사전 정의 답변으로 처리 가능한 질문은 LLM 호출 없이 응답
3. **LLM 호출**: Cloudflare Worker 프록시 경유 — API 키를 기기에 두지 않고, 기기별/전역 일일 한도와 서버 측 금지어 필터(클라이언트와 동일 목록)로 직접 호출 남용까지 방어

복기 코치는 온디바이스 Apple FoundationModels를 우선 사용하고(동일 데이터 재질문 캐시, 미지원 기기는 규칙 기반 폴백), 분석 이벤트는 네트워크 전송 없이 로컬 JSONL로만 기록합니다.

## 빌드

```bash
open SEED/SEED.xcodeproj
```

- Xcode 26 / iOS 18 SDK 필요
- AI 튜터의 클라이언트 토큰이 담긴 `SEED/SEED/Learn/TutorSecrets.swift`는 공개 저장소 특성상 gitignore 되어 있습니다. 빌드하려면 `enum TutorSecrets { static let clientToken = "..." }` 형태로 해당 파일을 추가해 주세요.
